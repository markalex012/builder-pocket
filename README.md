# קו ישר — פלס ומצפן בכיס

אתר סטטי בעברית עם פלס דו־צירי ומצפן. משתמש ב־DeviceOrientationEvent ובכיוון מוחלט בלבד עבור המצפן. כולל אפס יחסי, הקפאת קריאה ומצב הדגמה מסומן.

## בדיקה בטלפון
פתחו ב־Chrome ב־Samsung Galaxy דרך HTTPS ולחצו על הפעלת חיישנים. הניחו את הטלפון שטוח, הטו אותו ובדקו שהפלס משתנה; סובבו אותו ובדקו את המצפן. תמיכת החיישנים תלויה בדגם ובדפדפן. נתוני החיישנים אינם נשלחים לשרת.

כלי עזר ללמידה ולהערכה; אינו תחליף למכשיר בנייה מכויל. בדיקות חישוב וממשק בוצעו; בדיקה פיזית בטלפון נדרשת בנפרד.

## קבצים
index.html — ממשק; sensor-math.js — חישובי הטיה; app.js — הרשאות, חיישנים ובקרות. ללא התקנה או תלויות.
